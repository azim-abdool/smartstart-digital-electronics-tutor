# Updating the existing GitHub Pages tutor

1. Download and unzip `smartstart-tutor-v0.2.zip`.
2. Open the existing GitHub repository.
3. Choose **Add file → Upload files**.
4. Drag all files and folders from inside `smartstart-tutor-v0.2` into the upload area.
5. Allow GitHub to replace the existing `index.html`.
6. Commit with a message such as `Add integrated tutor shell and Digital Foundations`.
7. Open the same GitHub Pages URL after deployment completes.

The WordPress Advanced iFrame continues to use the existing URL. No WordPress edit should be required.
