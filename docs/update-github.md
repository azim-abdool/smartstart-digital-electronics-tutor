# Updating the GitHub Pages tutor to v0.4

1. Download and unzip `smartstart-tutor-v0.4.zip`.
2. Open the existing GitHub repository used for the tutor.
3. Choose **Add file → Upload files**.
4. Open the extracted `smartstart-tutor-v0.4` folder.
5. Upload everything **inside** that folder, preserving the folders.
6. Allow GitHub to replace existing files with the same names.
7. Commit with a message such as `Add Boolean Design activities`.
8. Open the existing GitHub Pages URL after deployment completes.

The GitHub Pages URL and the WordPress Advanced iFrame shortcode do not change.

## Expected new paths

- `activities/boolean-design/algebra/`
- `activities/boolean-design/truth-tables/`
- `activities/boolean-design/canonical-forms/`
