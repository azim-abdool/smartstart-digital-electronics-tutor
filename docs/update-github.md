# Updating GitHub Pages to v0.6

1. Unzip `smartstart-tutor-v0.6.zip`.
2. Open the existing GitHub repository used for the tutor.
3. Choose **Add file → Upload files**.
4. Upload everything inside the extracted `smartstart-tutor-v0.6` folder.
5. Allow GitHub to replace existing files.
6. Commit with a message such as `Restore Data Representation module`.
7. Open the existing GitHub Pages URL after deployment completes.

The WordPress Advanced iFrame shortcode and URL remain unchanged.
