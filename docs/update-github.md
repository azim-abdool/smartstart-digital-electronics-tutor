# Updating the GitHub Pages tutor to v0.8

1. Download and extract `smartstart-tutor-v0.8.zip`.
2. Open the existing GitHub repository used for the tutor.
3. Choose **Add file → Upload files**.
4. Upload everything inside the extracted `smartstart-tutor-v0.8` folder.
5. Allow GitHub to replace files with the same names.
6. Commit with a message such as `Add Sequential Logic module`.
7. Open the existing GitHub Pages URL after deployment finishes.

The GitHub Pages URL and Advanced iFrame shortcode remain unchanged.
