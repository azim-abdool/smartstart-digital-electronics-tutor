# Updating the existing GitHub Pages tutor to v0.3

1. Download and unzip `smartstart-tutor-v0.3.zip`.
2. Open the existing GitHub repository that currently hosts the tutor.
3. Choose **Add file → Upload files**.
4. Open the extracted `smartstart-tutor-v0.3` folder and upload everything inside it.
5. Allow GitHub to replace existing files such as `index.html`, `assets/site.js`, and the module pages.
6. Commit with a message such as `Add Logic Fundamentals gate activity`.
7. Open the same GitHub Pages URL after deployment completes.

The WordPress Advanced iFrame continues to use the existing URL. No WordPress edit is required.

## What v0.3 adds

- Module 2 is now available from the home page and menu.
- Interactive AND, OR, and NOT gate explorer.
- Common gate symbols: AND, OR, NAND, NOR, buffer, and inverter.
- Recovered De Morgan relationships from the original tutor.
- Truth-table completion activity with saved completion progress.
