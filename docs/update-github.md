# Updating GitHub Pages to v0.7

1. Download and unzip `smartstart-tutor-v0.7.zip`.
2. Open the existing GitHub repository.
3. Select **Add file → Upload files**.
4. Upload everything inside the extracted `smartstart-tutor-v0.7` folder.
5. Allow GitHub to replace existing files and add the new `activities/combinational-circuits` folder.
6. Commit with a message such as `Complete Module 5 combinational circuits`.

The Pages address and WordPress iframe shortcode remain unchanged.
